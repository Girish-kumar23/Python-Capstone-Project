# Python Capstone Project

## Project Description
This project is a Python-based application developed as part of the Python Capstone Project.

## Technologies Used
- Python
- SQLite
- Pandas
- Matplotlib
- Web Scraping
- CSV

## Files
- main.py - Main application
- scraper.py - Web scraping functionality
- database.py - Database operations
- seed.py - Database initialization
- client.py - Client-side functionality
- books.db - SQLite database
- exported_books.csv - Exported data
- price_vs_rating.png - Data visualization
- requirements.txt - Python dependencies

## How to Run
Install dependencies:

pip install -r requirements.txt

Then run:

python main.py
